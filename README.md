## 🌟 Key Features of This Portfolio

### 🕷️ 1. Interactive Silk Spider Cursor Engine
* **Authentic 3D Peacock Jumping Spider (*Maratus volans*):** Procedural rendering with an ivory/scarlet fan shield, emerald-teal metallic carapace with white anchor crest, four front-facing glossy eyes with spherical glints, and fluffy mint pedipalps.
* **8 Banded Zebra Legs (Inverse Kinematics):** 2-bone IK joints with realistic stepping gait, stride phases, and soft drop shadow.
* **Right-Click Web Net Blast:** Intercepted at document capture phase (`capture: true`) — right-clicking blasts a full radial spiderweb net with concentric rings and a lifeline tether, followed by an authentic recoil jump.
* **Idle Look-Up Behavior:** As soon as mouse/touch movement pauses, the spider smoothly rotates to face straight **UPWARDS (`-Math.PI / 2`)** to gaze directly at the user with dilated eyes and twitching pedipalps.
* **Web Lifespan & Dissolve:** Webs stay fully visible for **~8.5 to 9 seconds**, then gracefully dissolve over 3 seconds to keep the screen clean.
* **100% Touch & Mobile Support:** Automatically scales down to ~58% size on mobile devices (`<480px / <768px`) so it never covers content. Supports drag tracking, single-tap anchor lines, and **double-tap web nets** with zero lag (`passive: true`).
* **Zero Click Interference:** Both container and canvas use `pointer-events: none`, allowing every button, link, and input form on the page to be clicked normally.

### 🪐 2. Interactive 3D WebGL Multiverse Core (`SpiderHolo3D`)
* Powered by **Three.js** with hardware-accelerated rendering.
* 360° interactive rotation via mouse drag or mobile touch with acceleration lerp smoothing.
* **Zero-Lag Architecture:** Capped device pixel ratio (1.5 max) and `IntersectionObserver` auto-pause when out of viewport to conserve battery and GPU resources.

### 🎵 3. Sunflower Floating Vinyl Player
* Cinematic soundtrack audio player with animated equalizer waveforms, rotating vinyl record disc, track metadata, and ambient volume control.

### 📝 4. Live Cloud Sticky Notes Board
* Real-time visitor messaging board backed by **Firebase (Firestore / Cloud Sync)** with custom neon multiverse sticky styling, category filters, and live message counter.

### ⚡ 5. Spider-Sense Cyberpunk Telemetry HUD

## 🚀 Getting Started Locally

### Prerequisites
* **Node.js** (v18.0.0 or higher recommended)
* **npm** or **pnpm**

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/ddevguru/spiderman-portfolio.git
   cd spiderman-portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the local development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:5173](http://localhost:5173) in your browser.

4. **Build for production:**
   ```bash
   npm run build
   ```
   The production-ready artifacts will be generated inside the `dist/` directory.

## 🌐 Deployment (Netlify & Vercel)

### Deploying to Netlify (Recommended)

#### Option A: Drag & Drop (Instant)
1. Log in to [app.netlify.com](https://app.netlify.com/).
2. Navigate to **Sites** -> **Add new site** -> **Deploy manually**.
3. Drag and drop the `dist/` folder directly into the upload area.
4. Your site will be live instantly!

#### Option B: GitHub Integration
1. Connect your GitHub repository to Netlify.
2. Netlify will auto-detect the configuration via [netlify.toml](netlify.toml):
   * **Build Command:** `npm run build`
   * **Publish Directory:** `dist`
3. Click **Deploy Site**.

*Note: The project includes `public/_redirects` to ensure seamless SPA client-side routing on page refreshes.*
